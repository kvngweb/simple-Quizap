# A simple Quiz App that presents multiple-choice questions to the user and calculates their score at the end.


# Question Display 
1. Shows one question at a time with multiple choices.
2. Clicking an answer highlights it as correct(green) or incorrect (red)
3. Disables all buttons after selection.

# Score Tracking
1. keeps track of correct answers.
2. Updates the score at the end.

# Progress Indicator
1. Displays "Question X of Y" at the top.

# Results Screen
1. Shows final score after all questions.
2. allows user to restart the quiz.
